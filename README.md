# Tierra 3D — Web Animada

Proyecto web centrado en el planeta Tierra con animaciones y transiciones en CSS, controles interactivos mediante estados y una página secundaria de guía (`pia.html`).

## Estructura del proyecto

- `index.html`: página principal con el visor 3D del planeta Tierra, controles de ángulo/animación y explicaciones de cada modo.
- `guia.html`: página secundaria con la guía y documentación de los movimientos y efectos aplicados.
- `estilos.css`: hoja de estilos principal con la estructura visual, diseño responsive y apariencia del planeta.
- `animaciones.css`: hoja de estilos dedicada a las transiciones, animaciones (`@keyframes`), transformaciones 3D y ajustes de accesibilidad (`prefers-reduced-motion`).
- Carpetas complementarias (según organización de entrega): `css/`, `js/`, `img/`, `grabaciones/` y `capturas/`.

## Características principales

- **Visor y animaciones en 3D:** rotación y cambios visuales en el planeta Tierra para explorar sus distintas partes y fenómenos.
- **Interactividad sin depender de JavaScript pesado:** cambio de modos y ángulos mediante controles y selectores CSS.
- **Accesibilidad:** foco visible en elementos interactivos y soporte para `prefers-reduced-motion`.
- **Diseño adaptable:** pensado para verse correctamente en distintas resoluciones sin desbordamientos horizontales.

## Herramientas y recursos

- Maquetación y estilos desarrollados con **HTML5** y **CSS3** (editados con **Sublime Text** y probados en el navegador).
- Apoyo de inteligencia artificial utilizado para estructurar ideas, redactar comentarios y elaborar la documentación del proyecto, revisado y ajustado a la versión final.
