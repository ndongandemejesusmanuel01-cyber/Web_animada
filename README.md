## 📂 Estructura del proyecto

| Archivo / Carpeta | Descripción |
| :--- | :--- |
| `index.html` | Página principal con el visor 3D del planeta Tierra, controles de ángulo/animación y explicaciones de cada modo. |
| `guia.html` | Página secundaria con la guía y documentación de los movimientos y efectos aplicados. |
| `estilos.css` | Hoja de estilos principal con la estructura visual, diseño responsive y apariencia del planeta. |
| `animaciones.css` | Hoja de estilos dedicada a transiciones, animaciones (`@keyframes`), transformaciones 3D y `prefers-reduced-motion`. |
| `capturas/` y `grabaciones/` | Carpetas de evidencia visual del funcionamiento y comprobaciones del proyecto (si aplican en la entrega). |

---

## ✨ Características principales

* 🌐 **Visor y animaciones 3D:** rotación y cambios visuales en el planeta Tierra para explorar distintos modos y efectos.
* 🎛️ **Controles interactivos:** cambio de estados y ángulos de forma fluida mediante HTML y CSS.
* ♿ **Accesibilidad cuidada:** foco visible en elementos interactivos y soporte para `prefers-reduced-motion`.
* 📱 **Diseño adaptable:** preparado para distintos anchos de pantalla evitando desbordamientos horizontales.
